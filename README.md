# Calculation Methods

## Description

В этом репозитории собраны мои лабораторные работы по предмету "Методы Вычислений" за 1 семестр 2 курса
Код организован НЕ в соотвествии с правилами и структурой go-проектов. Это сделано в целях доступности каждой отдельной папки как самостоятельного проекта без зависимостей

## Usage

После скачивания/клонирования выполните:

```bash
go mod download
```
